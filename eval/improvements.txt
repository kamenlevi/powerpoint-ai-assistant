To get the title of a specific slide, use the getSlideByIndex method and load the shapes with the placeholderFormat and textRange properties.
```javascript
// Get the title of a specific slide
const slideIndex = 1;
const slide = await getSlideByIndex(slideIndex);
slide.shapes.load("items/placeholderFormat/type, items/textFrame/textRange/text");
await context.sync();
const titleShape = slide.shapes.items.find(s => s.placeholderFormat.type === "title");
return `Slide ${slideIndex + 1} title: ${titleShape.textFrame.textRange.text}`;
```
