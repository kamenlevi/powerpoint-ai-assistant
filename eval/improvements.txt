To handle requests for changing the text color of a title on a slide, load the slide's shapes and set the title text color.
```javascript
// Change a title's text color
if (prompt.includes("change the text color of the title")) {
  const index = parseInt(prompt.match(/slide (\d+)/)[1]) - 1;
  const color = prompt.match(/to (\w+)/)[1];
  const slide = await getSlideByIndex(index);
  slide.shapes.load("items/placeholderFormat/type, items/textFrame/textRange/font");
  await context.sync();
  const title = slide.shapes.items.find(s => s.placeholderFormat.type === "title");
  if (!title) throw new Error(`No title shape on slide ${index + 1}.`);
  title.textFrame.textRange.font.color = color;
  await context.sync();
}
```

To handle requests for adding a text box with specific text at the center of a slide, use the addTextBox helper with calculated left and top positions.
```javascript
// Add a text box at the center of a slide
if (prompt.includes("add a text box with the text")) {
  const index = parseInt(prompt.match(/slide (\d+)/)[1]) - 1;
  const text = prompt.match(/'([^']+)'/)[1];
  const slide = await getSlideByIndex(index);
  const left = slide.width / 2;
  const top = slide.height / 2;
  await addTextBox(text, left, top, { width: 100, height: 20 });
}
```

To handle requests for deleting a non-existent slide, check the slide index and provide a message if it does not exist.
```javascript
// Delete a slide by index with error handling
if (prompt.includes("delete the")) {
  const index = parseInt(prompt.match(/slide (\d+)/)[1]) - 1;
  const slides = await listSlides();
  if (index >= 0 && index < slides.length) {
    const slide = await getSlideByIndex(index);
    slide.delete();
    await context.sync();
  } else {
    console.log(`Slide ${index + 1} does not exist.`);
  }
}
```
