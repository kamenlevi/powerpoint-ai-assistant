To handle requests for adding a hyperlink to specific text on a slide, find the shape with the matching text and set the hyperlink.
```javascript
if (prompt.includes("Add a hyperlink to the text")) {
  const index = parseInt(prompt.match(/slide (\d+)/)[1]) - 1;
  const text = prompt.match(/'([^']+)'/)[1];
  const url = prompt.match(/https?:\/\/([^']+)/)[1];
  const slide = await getSlideByIndex(index);
  slide.shapes.load("items/textFrame/textRange");
  await context.sync();
  const shape = slide.shapes.items.find(s => s.textFrame.textRange.text.includes(text));
  if (shape) {
    const textRange = shape.textFrame.textRange;
    textRange.hyperlink.address = url;
  }
  await context.sync();
}
```
