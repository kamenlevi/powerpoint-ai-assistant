To handle web search limitations, suggest using addTextBox for static messages.
```javascript
// Add static message when web search is not possible
const message = "Current weather not available.";
const slide = await getCurrentSlide();
await addTextBox(slide.id, message, { left: 100, top: 100, width: 300, height: 50 });
```

For font changes, ensure the shape is loaded with the correct properties.
```javascript
// Change font of body text
const slide = await getSlideByIndex(0);
slide.shapes.load("items/placeholderFormat/type, items/textFrame/textRange/font");
await context.sync();
const body = slide.shapes.items.find(s => s.placeholderFormat.type === "body");
if (body) {
  body.textFrame.textRange.font.name = "Calibri";
  await context.sync();
}
```

To insert images, use the insertImage helper with correct parameters.
```javascript
// Insert a picture of a cat
await insertImage(-1, "animals", ["cat"], { left: 100, top: 100, width: 200, height: 200 });
await context.sync();
```

For single-slide presentations, apply a default theme after adding the slide.
```javascript
// Generate a single-slide presentation
await addSlide("title", "Hello World", "", "");
await applyTheme("Default Theme");
```

To delete a slide, verify its existence and use the delete method.
```javascript
// Delete the second slide
const index = 1;
const slides = await listSlides();
if (index >= 0 && index < slides.length) {
  const slide = await getSlideByIndex(index);
  slide.delete();
  await context.sync();
}
```

For hyperlinks to specific text, find the shape and update its hyperlink.
```javascript
// Add hyperlink to specific text
const slide = await getSlideByIndex(0);
slide.shapes.load("items/textFrame/hyperlink, items/textFrame/textRange/text");
await context.sync();
const shape = slide.shapes.items.find(s => s.textFrame.textRange.text.includes("Home"));
if (shape) {
  shape.textFrame.textRange.hyperlink.address = "https://www.example.com";
  await context.sync();
}
```
