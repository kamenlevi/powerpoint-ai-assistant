To replace text across the deck, iterate through all shapes and notes pages.
```javascript
// Replace all instances of 'old' with 'new' across the deck
presentation.slides.load("items/id, items/shapes/items/textFrame/textRange/text, items/notesPage/notesTextFrame/textRange/text");
await context.sync();
for (const slide of presentation.slides.items) {
  for (const shape of slide.shapes.items) {
    try {
      shape.textFrame.textRange.text = shape.textFrame.textRange.text.replace(/old/g, "new");
    } catch (e) {}
  }
  try {
    slide.notesPage.notesTextFrame.textRange.text = slide.notesPage.notesTextFrame.textRange.text.replace(/old/g, "new");
  } catch (e) {}
}
await context.sync();
```

When inserting an image, specify the target slide index.
```javascript
// Insert an image on a specific slide
await insertImage(0, "image", ["tag1", "tag2"], { left: 0, top: 0, width: 100, height: 100 });
```

To add a hyperlink to specific text, find the shape containing the text and update its hyperlink.
```javascript
// Add a hyperlink to specific text on a slide
const slide = await getSlideByIndex(0);
slide.shapes.load("items/textFrame/hyperlink, items/textFrame/textRange/text");
await context.sync();
const shape = slide.shapes.items.find(s => s.textFrame.textRange.text.includes("specific text"));
if (shape) {
  const textRange = shape.textFrame.getTextRange("specific text");
  textRange.hyperlink.address = "https://www.example.com";
  await context.sync();
}
```

To delete a slide, verify its existence and use the slide.delete function.
```javascript
// Delete a slide by index
const slides = await listSlides();
if (slides.length > 1) {
  const slide = await getSlideByIndex(1);
  slide.delete();
  await context.sync();
}
```
