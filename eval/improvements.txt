To replace text across the entire deck, including notes and all shapes, use a comprehensive approach.
```javascript
// Replace text across the deck
presentation.slides.load("items/shapes/items/textFrame/textRange/text, items/notesPage/notesTextFrame/textRange/text");
await context.sync();
for (const slide of presentation.slides.items) {
  for (const shape of slide.shapes.items) {
    try {
      shape.textFrame.textRange.text = shape.textFrame.textRange.text.replace(/Acme/g, "Globex");
    } catch (e) {}
  }
  try {
    slide.notesPage.notesTextFrame.textRange.text = slide.notesPage.notesTextFrame.textRange.text.replace(/Acme/g, "Globex");
  } catch (e) {}
  await context.sync();
}
```

To delete a slide by its position, verify the slide exists and then delete it.
```javascript
// Delete a slide by position
const index = 1; // Second slide
const slides = await listSlides();
if (index >= 0 && index < slides.length) {
  const slide = await getSlideByIndex(index);
  slide.delete();
  await context.sync();
} else {
  throw new Error(`Slide ${index} does not exist.`);
}
```
