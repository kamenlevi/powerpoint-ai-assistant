To handle requests for deleting a slide, handle the case where the slide does not exist.
```javascript
if (prompt.includes("delete the") && prompt.includes("slide")) {
  const index = prompt.match(/delete the (\d+) slide/)[1];
  try {
    const slide = await getSlideByIndex(index - 1);
    slide.delete();
    await context.sync();
  } catch (e) {
    console.log(`Slide ${index} does not exist.`);
  }
}
```
