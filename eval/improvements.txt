To add a hyperlink to specific text, find the shape containing the text and update its hyperlink, preserving existing text.
```javascript
// Add a hyperlink to specific text, preserving existing text
const slide = await getSlideByIndex(0);
slide.shapes.load("items/textFrame/hyperlink, items/textFrame/textRange/text");
await context.sync();
const shape = slide.shapes.items.find(s => s.textFrame.textRange.text.includes("Learn More"));
if (shape) {
  const textRange = shape.textFrame.getTextRange("Learn More");
  textRange.hyperlink.address = "https://www.example.com";
  await context.sync();
}
```

To move a shape, update its left property.
```javascript
// Move a shape to the left
const slide = await getSlideByIndex(0);
slide.shapes.load("items/placeholderFormat/type, items/left");
await context.sync();
const title = slide.shapes.items.find(s => s.placeholderFormat.type === "title");
if (title) {
  title.left -= 20;
  await context.sync();
}
```
